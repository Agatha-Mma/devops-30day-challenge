# DevOps Project: Static Website Deployment with Nginx on Linux

## Project Overview

This project demonstrates how to deploy and manage a static website on a Linux server using **Nginx**, including logging, monitoring, and automated recovery.

The objective was to simulate a **basic production-ready web environment** by:

- Deploying a static HTML website
- Configuring an Nginx web server
- Implementing security headers
- Creating a health monitoring endpoint
- Writing a Bash monitoring script to automatically restart the service if it fails

This project was completed as part of my **Linux DevOps Hands-on Labs**.
